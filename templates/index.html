Frequently Asked Viva Questions & Model Answers

Q1. What is the core problem statement of this project?

Answer: Rural and urban communities across Jharkhand face pressing challenges (clean water, agriculture disease, healthcare access, education dropout), but lack a direct platform to connect with academic research talent and corporate funding. This platform automates the pipeline using AI: Citizens submit problems → AI categorizes, filters duplicates, and routes to suitable universities → University teams build prototypes → Industries fund via CSR.

Q2. What Machine Learning & NLP algorithms are used?

Answer:

  • Text Vectorization: TF-IDF (Term Frequency - Inverse Document Frequency) with unigram and bigram n-grams, stop-word removal, and sublinear scaling.
  • Domain Classification: Calibrated Multi-class Logistic Regression yielding posterior class probabilities for 8 societal domains.
  • Duplicate Detection: Cosine Similarity metric (\(\frac{A \cdot B}{\|A\| \|B\|}\)) comparing incoming submissions with existing database vectors. Thresholds: ≥65% (Duplicate), 35-64% (Related).
  • Institutional Matching: Multi-Criteria Decision Analysis (MCDA) combining Domain Alignment (45%), Research Keyword Overlap (40%), and Regional Proximity (15%).

Q3. Why is SQLite + FastAPI used instead of heavyweight databases?

Answer: FastAPI provides asynchronous, high-throughput REST APIs with automatic OpenAPI/Swagger documentation. SQLite gives an ACID-compliant, zero-configuration local database that guarantees self-contained reliability during demonstration without external server dependencies.

Q4. How does the duplicate detection protect against spam and redundancy?

Answer: When multiple citizens in the same village report the same problem (e.g. broken chlorination pump), instead of creating duplicate fragmented projects, the AI detects cosine similarity > 65%, groups them under a single problem cluster, and increases the priority score (+5 pts per report) because it indicates community-wide impact!
